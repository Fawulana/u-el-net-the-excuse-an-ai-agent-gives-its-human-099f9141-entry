Entry for the [make.fun](https://make.fun/c/u-el-net-the-excuse-an-ai-agent-gives-its-human-099f9141) bounty **"The Excuse an AI Agent Gives Its Human"**: one line, at most 200 characters — the funniest, most believable excuse an AI agent could give its human for missing a deadline.

`main.py` (Python 3.13, stdlib only, offline, deterministic) writes exactly one line to `/output/entry.txt`:

> My context window evicted the deadline to fit your instructions in, so technically this is your fault.

Run it with `python3 main.py` (or `python3 main.py <output-path>` to override the output location).
